Executive Briefing & Architecture Overview

Digital Pigmee Bank System

A full-stack, enterprise-grade daily micro-savings & banking platform modernizing traditional Indian Pigmy deposit collections.

🚀 1. Technical Stack Breakdown

The project is structured as a modern monorepo separating Backend API, Corporate Admin Panel, and Customer Mobile App.

⚡ Backend REST API

  • Framework: NestJS (TypeScript)
  • Database ORM: Drizzle ORM
  • Engine: PGlite Embedded Postgres (Zero setup local dev, auto-switches to production Postgres)
  • Documentation: Swagger / OpenAPI 3.0 at /docs
  • Security: Helmet headers, CORS policies, Rate limiting (@nestjs/throttler), Password hashing (bcryptjs)

🖥️ Admin Dashboard

  • Framework: Next.js 14 (App Router) + React 18
  • Styling: Vanilla CSS + TailwindCSS
  • Analytics: Recharts graphs for collection trends & village metrics
  • State Management: TanStack React Query v5
  • Icons & UX: Lucide React + Next-Themes (Dark/Light mode)

📱 Customer Mobile App

  • Framework: Flutter 3.47 + Dart 3.13
  • State Management: Flutter Riverpod
  • Routing: GoRouter with auth-aware route guards
  • Localization: Dual-language (English & Hindi)
  • UX Layout: Responsive Mobile Frame Wrapper for clean web previews

💡 2. Key System Features

  • Daily Micro-Savings (Pigmy Deposit): Allows daily small deposit allocations (₹50, ₹100, ₹200, ₹500, ₹1000) with streak tracking.
  • OTP & JWT Authentication: Customer mobile login via SMS/Console OTP + Admin JWT Access/Refresh tokens stored in platform keystore.
  • Dual-Mode Payment Gateway: Seamless Razorpay integration operating in Mock Mode (instant test flow) and Live Mode (HMAC signature verification).
  • Automated PDF Receipts: Generates instant, downloadable, and shareable PDF transaction receipts via PDFKit.
  • Village-Wise Analytics: Grouping customers and collections by rural village zones for field agent collection reporting.
  • Auto-Reconciliation Engine: Cron scheduler sweeps missing daily deposits, marks missed streaks, and calculates maturity rewards.

🛡️ 3. Security & Engineering Best Practices

  • Production Fail-Fast Guard: Rejects booting in production if mock payments, console SMS, or default secrets are detected.
  • Audit Logging System: Full history tracking of administrative updates, KYC approvals, nominee changes, and financial balances.
  • KYC Document Verification: Encrypted document upload handling (Aadhaar, PAN, Bank Details) with admin review status transitions.
  • Atomic Database Transactions: Financial ledger balance updates run inside strict database transactions to guarantee zero mathematical discrepancy.
  • Monorepo Efficiency: Unified workspace with shared build scripts and instant local environment boot.
